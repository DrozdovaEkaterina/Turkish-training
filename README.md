# Turkish Steps

Простой адаптивный сайт для изучения турецкого языка через бытовые ситуации.

## Что внутри

- 4 интерактивных мини-урока: магазин, автобус, разговор с прохожим о кошках, заказ в кафе.
- Русский интерфейс с турецкими фразами и переводом.
- Короткие задания с выбором ответа и мгновенной обратной связью.
- Локальное сохранение прогресса в браузере через `localStorage`.
- Быстрое повторение фраз в формате карточек.
- Полностью статический запуск без backend.

## Как открыть

Откройте `index.html` в браузере или включите GitHub Pages для ветки `main` и корневой папки репозитория.
